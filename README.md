# Bordvakt – landningssida

Landningssida för Bordvakt, AI-driven servicestöd för restauranger.

## Filer

| Fil | Innehåll |
|---|---|
| `index.html` | Sidans HTML |
| `styles.css` | Grundstil, animationer och fokusmarkering |
| `script.js` | Notis-animationen, ROI-kalkylatorn och formuläret |
| `design-kalla/` | Källfiler från design-canvasen (används inte av webbsidan) |

## Publicera med GitHub Pages

1. Gå till **Settings › Pages** i repot.
2. Under **Source**, välj **Deploy from a branch**.
3. Välj grenen `main` och mappen `/ (root)`, tryck **Save**.
4. Efter någon minut ligger sidan på `https://<ditt-användarnamn>.github.io/<repo-namn>/`.

## Att göra innan lansering

- [ ] Koppla formuläret i `script.js` (se `TODO`) till t.ex. Formspree eller e-post.
- [ ] Byt Calendly-länken i `index.html` mot er egen.
- [ ] Fyll i `[FÖRETAGSNAMN, ORG.NR]`, `[E-POST]` och `[TELEFON]` i sidfoten.
